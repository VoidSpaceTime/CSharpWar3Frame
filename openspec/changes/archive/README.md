# OpenSpec 归档变更说明

## 归档语义

- `openspec/changes/archive/` 存放由官方 `openspec archive` 关闭的变更。**归档即官方“完成动作”**：change 的 delta specs 已合并进 `openspec/specs/`，目录再移入此处保留审计历史。
- 与官方一致：归档表示该变更已走完生命周期，主 `specs/` 反映其合并后的当前真相。
- 本仓库附加约定：`proposal.md` 的 `状态` 字段与 `summary.md` 为人类可读追踪证据，**不改变官方归档语义**，也不阻塞 `archive`。

## 2026-08-13 批量归档历史边界

在 2026-08-13 进行的批量归档（目录名前缀为 `2026-08-13-`）属于历史清理，早于本仓库对齐官方工作流：
- **历史闭环**：这些变更仅作历史留存，未经过逐一的实施状态审计，且其 delta specs 未合并进 `openspec/specs/`。
- **非当前状态证据**：对于其中未显式标注状态或缺失 `summary.md` 的变更，不能直接作为当前项目状态的证据。
- **验证方式**：若需确认其对应的功能是否已在当前代码中生效，必须直接检查当前代码库、Git 提交历史以及其自身的工件，而不能仅凭其存在于归档目录中来推断。
